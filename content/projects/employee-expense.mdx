### Overview
Designed and customized an expense management portal allowing employees to submit reimbursements digitally while enabling managers to review, approve, and track expenses efficiently.

### Problem
Expense reimbursement was handled through spreadsheets and email approvals, causing delays, duplicate records, and limited visibility into expense status.

### Solution
Developed a digital expense workflow integrated within Odoo that automated expense submission, approval routing, accounting integration, and reporting.

### Key Features
- Expense Submission Portal
- Receipt Upload
- Approval Workflow
- Multi-level Manager Approval
- Accounting Integration
- Expense Categories
- Status Tracking
- Expense Analytics Dashboard

### Challenges
- Managing multi-level approval logic.
- File attachment handling.
- Accounting synchronization.
- Role-based access control.

### Results
- Significantly reduced reimbursement processing time.
- Improved transparency for employees.
- Centralized expense records.
- Automated approval notifications.

### What I Learned
- Workflow automation
- Accounting integration
- Security and access rights
- Portal customization
